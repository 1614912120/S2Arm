# 鸿蒙现有本地出包工具（迁移参考 Draft）

这是现有私用出包链的自有源码快照，供协作者复用和迁移，不表示已经接通当前上游统一目标适配器，也不作为新的公共离线库协议。旧环境有已构建依赖；干净公开树尚未完成端到端出包验证。

入口：`python pack/targets/ohos/cli.py --help`。只运行帮助不会连接设备。实际构建读取 `--config` 指定的本地JSON；游戏、密钥、证书、签名profile、工作目录和依赖库均由用户在本机提供。配置文件和生成结果不进仓库。公开开发包身份为 `io.s2arm.ohos.dev`。

- `cli.py`：导入/准备/构建、HAP与资源分包、部署和启动；带设备的动作只在用户明确执行对应子命令时进行。
- `patch_catalog.py` / `PATCHES.md`：按输入身份核对用户自有补丁目录；不附补丁或游戏地址表。
- `shader_extract.py` / `shader_package.py`：本地提取与打包流程源码；不附提取结果。
- `ohos/tools/direct`、`ohos/tools/shaders`、`ohos/shaders`：已有图形描述符、离线库与批处理工具，保留作为迁移参考；后续应接上游LibPack，不能据此另立公共协议。

配套源码：外壳 #1297、音频 #1298、运行时 #1301。当前快照可能仍有旧入口/构建产物路径依赖，需按这三片的干净树继续接通；不要求协作者重新实现已有能力。

本次验证：16个导入文件，Python源码语法检查通过，CLI帮助入口通过；敏感路径/凭据模式扫描0命中。未运行真实出包、签名、安装、游戏或性能测试。完整贡献检查已尝试，Windows前置工具环境不满足；无门禁全绿声明。

不公开：私用HAP、从游戏改写生成的载体、游戏着色器/缓存、资源包、存档、密钥、证书与私人配置。生成器源码与其输出明确分开。
